# 📚 Telix School Management System (V1)

A desktop-based School Management System developed in **Python** to simplify the management of students, teachers, and school records. 
This project serves as the first stable release of the Telix School Management System and focuses on providing essential administrative tools through a clean and easy-to-use graphical interface.

Version 1 is designed with simplicity, maintainability, and reliability in mind while laying the groundwork for future versions featuring authentication, databases, parent portals, financial management, and cloud-based functionality.

---

# ✨ Features

## Student Management

* Add new students
* Edit student records
* Delete student records
* Search students using Student ID
* View students by class

## Teacher Management

* Add new teachers
* Edit teacher records
* Delete teacher records
* Search teachers using Teacher ID

## Academic Records

* Modify student academic records
* Store academic information securely

## Financial Module

* Calculate school profit and loss

## Data Validation

* Prevent empty form submissions
* Validate student age
* Validate phone numbers
* Prevent duplicate Student IDs
* Prevent duplicate Teacher IDs
* Display user-friendly error messages

## Data Storage

* JSON-based persistent storage
* Automatic data backup before writing records

## User Experience

* Confirmation dialog before deleting records
* Improved application structure
* Better error handling
* Cleaner codebase

# 🚀 Getting Started

## Prerequisites

* Python 3.10 or later
* Git (optional)

## Installation

Clone the repository:

```bash
git clone https://github.com/SamuelNiiOdoiOddoye/School_Management_System.git
```

Navigate into the project:

```bash
cd School_Management_System
```

Run the application:

```bash
python main.py
```
